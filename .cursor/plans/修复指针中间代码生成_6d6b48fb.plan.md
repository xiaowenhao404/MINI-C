# 修复指针操作中间代码生成 Bug

## 问题分析

在 [src/utils/tree.c](src/utils/tree.c) 第 29-31 行：

```c
if (number == 1) {
    return va_arg(valist, Tree *);  // 直接返回传入指针
}
```

当调用 `createTree("ADDR_OF", 1, $2)` 时，返回的是 `$2` 本身，而非新节点。

导致 [src/frontend/yacc.y](src/frontend/yacc.y) 第 313-330 行：

```c
$$ = createTree("ADDR_OF", 1, $2);  // $$ == $2
$$->inner = "t47";                   // 同时修改了 $2->inner!
$$->code = mergeCode(..., $2->inner, ...);  // $2->inner 已变成 "t47"
```

生成错误代码：`t47 = addr t47`（自引用）

## 修复方案

在设置 `$$->inner` 之前，先保存 `$2->inner` 的原始值。

### 修改位置: [src/frontend/yacc.y](src/frontend/yacc.y) 第 311-334 行

**修复解引用操作 (*ptr)**：
- 在 `$$->inner = ...` 之前保存 `$2->inner` 到 `char* src_inner`
- 使用 `src_inner` 生成中间代码

**修复取地址操作 (&var)**：
- 同上，先保存 `$2->inner` 再修改 `$$->inner`
