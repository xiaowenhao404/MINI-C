# Mini-C 项目文档整理与创建计划

## 第一部分：清理工作

### 1.1 删除可再生中间文件（根目录）

删除以下编译过程中生成的文件：

- `lex.yy.c`, `yacc.tab.c`, `yacc.tab.h` - Flex/Bison 生成文件
- `compiler` - 编译器可执行文件
- `Lexical`, `Grammatical`, `Innercode` - 编译中间结果
- `assembly.asm` - 汇编代码
- `temp.o`, `temp_exe`, `test_error` - 临时目标文件和可执行文件
- `temp copy.c` - 临时副本

保留：

- `temp.c`, `test_error.c` - 用于测试的源文件

### 1.2 删除/整理 tests 目录中的冗余文件

- `tests/semantic/test_function_type.exe`, `test_type_system.exe` - Windows 可执行文件
