# 修复汇编生成器内存指令支持

## 问题根因

[scripts/asm_generator.py](scripts/asm_generator.py) 第 126-143 行的中间代码解析逻辑没有识别以下格式：

```javascript
t30 = load t29     -> 内存读取
store value addr   -> 内存写入  
t47 = addr var     -> 取地址
```

当遇到 `t30 = load t29` 时，代码将其错误解析为普通赋值 `('=', 'load', '_', 't30')`，导致后续在 `data.index('load')` 时失败。

## 修改方案

### 1. 在解析阶段添加 load/store/addr 识别

在 [scripts/asm_generator.py](scripts/asm_generator.py) 第 122 行 `elif len(ops) > 3 and ops[3] == "alloc":` 之后，添加对以下格式的解析：

```python
# t30 = load t29 格式（内存读取）
elif len(ops) > 4 and ops[3] == "load":
    addr_var = ops[4]
    four.append(('load', addr_var, '_', ops[1]))

# t47 = addr var 格式（取地址）
elif len(ops) > 4 and ops[3] == "addr":
    src_var = ops[4]
    four.append(('addr', src_var, '_', ops[1]))

# store value addr 格式（内存写入）- 需要单独处理
```



### 2. 添加 store 指令解析

`store` 指令格式特殊：`行号: store value addr`在第 97 行 `elif ops[1] == "arg":` 附近添加：

```python
elif ops[1] == "store":
    value = ops[2] if len(ops) > 2 else '_'
    addr = ops[3] if len(ops) > 3 else '_'
    four.append(('store', value, addr, '_'))
```



### 3. 验证汇编生成代码

第 689-734 行已有 `load`/`store`/`addr` 的汇编生成代码，但需要确认四元组格式匹配：

- `load`: `('load', addr_var, '_', result_var)` -> 需调整为 `(op, src, '_', dst)` 格式
- `addr`: `('addr', src_var, '_', result_var)` -> 需调整
- `store`: `('store', value, addr, '_')` -> 格式正确

## 实施检查清单

1. 在第 97 行附近添加 `store` 指令解析
2. 在第 122 行之后添加 `load` 和 `addr` 指令解析
3. 检查并调整第 689-734 行的汇编生成代码，确保四元组字段顺序一致
