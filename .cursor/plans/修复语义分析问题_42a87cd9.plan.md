## 问题2: 语法错误更具体

**文件**: [`src/frontend/yacc.y`](src/frontend/yacc.y) (yyerror函数, 第821-823行)**修改内容**: 检测常见语法错误模式并给出更具体提示

```c
void yyerror(const char* s) {
    extern char* yytext;
    extern int yylineno;
    
    // 根据 yytext 判断错误类型
    if (strcmp(yytext, "int") == 0 || strcmp(yytext, "float") == 0 || ...) {
        printf("[语法错误] 行 %d: 可能缺少分号\n", yylineno - 1);
    } else if (strcmp(yytext, "{") == 0) {
        printf("[语法错误] 行 %d: 括号不匹配，缺少 ')'\n", yylineno);
    } else {
        printf("[语法错误] 行 %d: %s\n", yylineno, s);
    }
}
```

### 3.3 函数参数计数错误

**文件**: [`src/semantic/semantic_analyzer.c`](src/semantic/semantic_analyzer.c) (count_arguments, 第1454-1467行)**原因**: ARG_LIST 结构处理逻辑需要修正**修复**: 重新实现 count_arguments：

```c
static int count_arguments(Tree *arg_list) {
    if (!arg_list) return 0;
    if (strcmp(arg_list->name, "ARG_LIST") == 0) {
        // ARG_LIST: leaves[0]=前面参数, leaves[1]=当前参数
        return count_arguments(arg_list->leaves[0]) + 
               count_arguments(arg_list->leaves[1]);
    }
    return 1;
}
```

## 问题4: 修复测试用例检测问题

### 4.1 变量重定义(3.2)、数组重定义(5.3)、指针重定义(6.2)

**原因**: hashMap导入后，符号已存在，analyze_variable_list 跳过了重定义检查**修复**: 在 `analyze_variable_list` 中，当不是初始声明时检测重定义:

- 需要区分 "声明时初始化" 和 "普通赋值"
- 对于纯声明语句（如 `int x;`），检查重定义

### 4.2 类型不匹配(4.1)、非左值赋值(4.2)

**原因**: 赋值表达式没有被正确识别和分析**修复**: 在 `analyze_statement` 或 `analyze_expression` 中添加对赋值表达式的处理

### 4.3 非数组下标访问(5.2)

**原因**: 数组访问检测未覆盖此情况**修复**: 在 `analyze_array_access` 或表达式分析中检测

### 4.4 Segmentation fault(6.1)

**原因**: `analyze_deref` 中可能有空指针访问**修复**: 添加空指针检查，并确保在解引用非指针时正确报错

### 4.5 数组下标类型(5.1)

**修复**: 确保 `analyze_array_access` 正确检测下标类型---
