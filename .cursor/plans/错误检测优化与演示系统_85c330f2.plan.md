# 错误检测优化与演示系统计划

## 目标

1. 错误输出格式统一为：`[错误类型] 行号: 错误描述`
2. Web端控制台清理无关信息，只保留关键错误信息
3. 创建演示专用的错误样例手册（每个样例是完整可编译文件）

---

## 实施步骤

### 1. 统一错误输出格式

**修改文件**: [src/semantic/semantic_analyzer.c](src/semantic/semantic_analyzer.c)将 `semantic_error()` 函数的输出格式从当前格式改为：

```c
// 当前格式
printf("语义错误: 变量 '%s' 未定义  line: %d\n", var_name, line);

// 修改为简洁格式
printf("[语义错误-变量未定义] 行 %d: 变量 '%s' 未声明\n", line, var_name);
```

**修改文件**: [src/frontend/yacc.y](src/frontend/yacc.y)统一 `yyerror()` 的输出格式：

```c
// 当前格式
printf("Error: %s\tline: %d\n", s, yylineno);

// 修改为
printf("[语法错误] 行 %d: %s\n", yylineno, s);
```



### 2. 清理Web端无关输出

**修改文件**: [web/app.py](web/app.py)

- 删除步骤编号（步骤 1/5, 2/5 等）
- 删除文件统计信息
- 删除命令回显（`$ wsl bash -c ...`）
- 只保留：错误信息、程序输出、编译状态

修改后的控制台输出示例：

```javascript
=== Mini-C 编译器 v3.0 ===

[语法错误] 行 5: syntax error
[语义错误-变量未定义] 行 8: 变量 'c' 未声明

❌ 编译失败，共 2 个错误
```
