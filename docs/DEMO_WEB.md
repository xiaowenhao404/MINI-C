## 环境准备

### 1. 确保 WSL 环境已安装必要工具

```bash
# 检查工具是否安装
which gcc flex bison nasm python3

# 如未安装，执行：
sudo apt update
sudo apt install -y gcc flex bison nasm python3 python3-pip
```

### 2. 安装 Python 依赖

```bash
cd Mini-C/web
pip3 install flask
```

### 3. 构建编译器

```bash
cd Mini-C
make clean
make
```

## 启动 Web 服务

### 步骤 1：进入 web 目录

```bash
cd Mini-C/web
```

### 步骤 2：启动 Flask 服务

```bash
python3 app.py
```

成功启动后会显示：

```

 * Debug mode: on
```

### 步骤 3：打开浏览器

在浏览器地址栏输入：

```
http://127.0.0.1:5000
```

## 功能演示

### 演示 1：整数运算

**输入代码：**

```c
void main() {
    int a = 10;
    int b = 20;
    int c = a + b;
    output(c);
}
```

**操作步骤：**

1. 在代码编辑器中输入上述代码
2. 点击 **[编译运行]** 按钮
3. 等待编译完成
4. 点击 **[程序输出]** 查看结果

**预期输出：**

```
30
```

### 查看编译过程

1. **词法分析结果**：点击 **[词法分析]** 标签

   - 显示所有识别的 Token
   - 包括：关键字、标识符、数字、运算符等

2. **语法分析结果**：点击 **[语法分析]** 标签

   - 显示语法树结构
   - 可以看到语法规则的归约过程

3. **中间代码**：点击 **[中间代码]** 标签

   - 显示三地址码
   - 格式：`行号: 操作`

4. **汇编代码**：点击 **[汇编代码]** 标签
   - 显示 x86-64 NASM 汇编
   - 可用于理解代码生成过程

## 常见问题

### Q1: 编译按钮点击后无反应？

**解决方案：**

1. 检查 Flask 服务是否正在运行
2. 查看终端是否有错误信息
3. 刷新页面重试

### Q2: 程序输出为空？

**可能原因：**

1. 代码语法错误 - 检查控制台输出
2. 没有调用 `output()` 函数
3. 程序运行时崩溃 - 检查指针/数组越界

### Q3: 汇编代码生成失败？

**解决方案：**

1. 确保已安装 Python3
2. 检查 `scripts/asm_generator.py` 是否存在
3. 查看控制台错误信息

### Q4: 浮点数显示不正确？

**说明：**

- 浮点数精度受限于 32 位 float
- 显示精度为小数点后 2 位

## 注意事项

1. **代码保存**：刷新页面会丢失代码，建议复制保存
2. **大型程序**：复杂程序可能需要较长编译时间
3. **错误处理**：语法错误会在控制台显示
4. **浏览器兼容**：推荐使用 Chrome 或 Firefox
