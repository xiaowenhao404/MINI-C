## 概述

**对应文件**: `src/frontend/yacc.y`, `src/utils/tree.c`, `src/utils/inner.c`

### 整体流程

```
AST (抽象语法树)
    ↓
语义动作生成 IR
    ↓
三地址码 → Innercode 文件
    ↓
标签替换
    ↓
最终中间代码
```

### 设计目标

1. **解耦前后端**：IR 作为前端和后端的桥梁
2. **支持优化**：所有优化在 IR 层面进行
3. **便于调试**：使用字符串表示，便于阅读和调试

## 三地址码设计

### 基本格式

```
行号: 操作
```

### 四元式结构

每条指令可以看作四元式 `(op, arg1, arg2, result)`：

```
result = arg1 op arg2
```

### 示例

```
1: a = 10
2: b = 20
3: t1 = a + b
4: output_int t1
```

## 标签系统

### 设计思路

使用符号标签替代硬编码行号，解决控制流跳转问题。

### 生成阶段

```
@WHILE_0_START:
t1 = i < 10
if t1 goto @WHILE_0_BODY
goto @WHILE_0_END
@WHILE_0_BODY:
...
goto @WHILE_0_START
@WHILE_0_END:
```

### 替换阶段

`replaceLabels()` 函数将标签替换为行号：

```
10: t1 = i < 10
11: if t1 goto 13
12: goto 16
13: ...
15: goto 10
16: ...
```

### 实现代码

```c
// yacc.y 中的标签生成
int label_id = 0;

while_expression
    : WHILE { 
        char* start = malloc(32);
        char* end = malloc(32);
        sprintf(start, "@WHILE_%d_START", label_id);
        sprintf(end, "@WHILE_%d_END", label_id++);
    }
    '(' expression ')' statement
    {
        $$ = createWhileNode(start, end, $4, $6);
    }
;
```

## 代码拼接机制

### mergeCode 函数

```c
char* mergeCode(int n, ...) {
    va_list args;
    va_start(args, n);
    
    // 计算总长度
    int total_len = 0;
    for (int i = 0; i < n; i++) {
        char* s = va_arg(args, char*);
        if (s) total_len += strlen(s);
    }
    
    // 分配并拼接
    char* result = malloc(total_len + 1);
    result[0] = '\0';
    
    va_start(args, n);
    for (int i = 0; i < n; i++) {
        char* s = va_arg(args, char*);
        if (s) strcat(result, s);
    }
    
    va_end(args);
    return result;
}
```

### 使用示例

```c
// 生成 t1 = a + b
$$->inner = mergeCode(2, "t", toString(inner_count++));
$$->code = mergeCode(8,
    $1->code,           // 左操作数代码
    $3->code,           // 右操作数代码
    "#", $$->inner,     // 结果变量
    " = ", $1->inner,   // 左操作数
    " + ", $3->inner,   // 运算符和右操作数
    "\n"
);
```

## 遇到的困难与解决方法

### 问题 1：行号管理混乱

**问题描述**：
多函数程序中行号重复，导致跳转目标错乱。

**解决方案**：
- 使用全局唯一行号
- 采用符号标签系统
- 代码生成完成后统一替换

### 问题 2：临时变量分配

**问题描述**：
临时变量名冲突，导致值被覆盖。

**解决方案**：
使用全局计数器生成唯一临时变量名：

```c
int inner_count = 0;

// 生成唯一临时变量
char* temp = mergeCode(2, "t", toString(inner_count++));
```

### 问题 3：嵌套控制流

**问题描述**：
嵌套的 if-else 和 while 标签冲突。

**解决方案**：
每个控制结构使用独立的标签 ID：

```c
// 每个 while 循环有唯一标签
@WHILE_0_START, @WHILE_0_END
@WHILE_1_START, @WHILE_1_END
...
```

### 问题 4：数组和指针的地址计算

**问题描述**：
数组访问需要计算偏移地址。

**解决方案**：
分解为多步操作：

```c
// arr[i] = 10
// 生成的中间代码：
t1 = i * 4           // 偏移量
t2 = arr + t1        // 地址计算
store 10 t2          // 存储
```
