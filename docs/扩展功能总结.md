## 概述

Mini-C 编译器在基础功能之上，实现了多项扩展功能。每项扩展都涉及词法分析、语法分析、语义分析、中间代码生成、汇编生成等多个模块的修改。

## 1. 实型数据 Float 扩展

### 实现思路

**词法分析**：识别浮点数字面量

```flex
{DIGIT}+"."{DIGIT}+   { yylval.fval = atof(yytext); return FLOAT_NUM; }
```

**语法分析**：类型声明支持 float

```yacc
type_specifier
    : INT    { $$ = TYPE_INT; }
    | FLOAT  { $$ = TYPE_FLOAT; }
    ;
```

**中间代码**：区分整型和浮点运算

```
t1 = a + b      // 整数加法
t2 = x f+ y     // 浮点加法（f+, f-, f*, f/）
```

**汇编生成**：使用 SSE 指令

```nasm
movss xmm0, [rbp-8]   ; 加载浮点数
addss xmm0, xmm1      ; 浮点加法
movss [rbp-16], xmm0  ; 存储结果
```

### 困难与解决

**问题**：printf 需要 double 参数  
**解决**：使用 `cvtss2sd` 将 float 转换为 double

## 2. 过程/函数调用

### 实现思路

**语法规则**：

```yacc
function_definition
    : type_specifier ID '(' parameter_list ')' compound_statement
    ;

function_call
    : ID '(' argument_list ')'
    ;
```

**中间代码**：

```
FUNC_BEGIN add
param a
param b
...
return t1
FUNC_END

arg 10
arg 20
t1 = call add 2
```

**汇编生成**：遵循 System V AMD64 ABI

```nasm
; 参数传递：rdi, rsi, rdx, rcx, r8, r9
mov edi, [rbp-8]    ; 第一个参数
mov esi, [rbp-16]   ; 第二个参数
call add
mov [rbp-24], eax   ; 保存返回值
```

### 困难与解决

**问题**：参数数量和类型检查  
**解决**：符号表记录函数签名，调用时验证

## 3. 数组运算 (多维)

### 实现思路

**声明**：

```c
int arr[10];      // 一维数组
int matrix[3][4]; // 二维数组
```

**中间代码**：

```
arr = alloc 40              // 分配 10 * 4 = 40 字节
t1 = i * 4                  // 计算偏移
t2 = arr + t1               // 计算地址
t3 = load t2                // 读取元素
store 10 t2                 // 写入元素
```

**汇编生成**：

```nasm
; arr[i] = 10
mov eax, [rbp-8]       ; 加载 i
imul eax, 4            ; 计算偏移
mov rbx, [rbp-16]      ; 加载数组基址
add rbx, rax           ; 计算元素地址
mov dword [rbx], 10    ; 存储值
```

### 困难与解决

**问题**：数组空间被后续变量覆盖  
**解决**：alloc 时预留足够的栈空间

## 4. 指针运算

### 实现思路

**语法规则**：

```yacc
unary_expression
    : '&' unary_expression    // 取地址
    | '*' unary_expression    // 解引用
    ;
```

**中间代码**：

```
t1 = addr val       // 取地址
t2 = load ptr       // 解引用读取
store 10 ptr        // 解引用写入
```

**汇编生成**：

```nasm
; t = addr val
lea rax, [rbp-8]       ; 获取 val 的地址
mov [rbp-16], rax      ; 存储到 t（64位）

; t = load ptr
mov rax, [rbp-16]      ; 加载指针值
mov eax, [rax]         ; 解引用
mov [rbp-24], eax      ; 存储结果
```

### 困难与解决

**问题**：`createTree(1)` 返回原节点导致值覆盖  
**解决**：先保存原值再赋值

```c
char* saved_inner = $2->inner;  // 先保存
$$ = createTree("DEREF", 1, $2);
$$->inner = ...;  // 赋值
```

## 5. 结构体 Struct

### 实现思路（框架）

**语法规则**：

```yacc
struct_specifier
    : STRUCT ID '{' struct_declaration_list '}'
    ;

struct_declaration
    : type_specifier ID ';'
    ;
```

**类型系统**：

```c
typedef struct {
    char *name;
    Type *type;
    int offset;  // 成员偏移
} StructMember;

typedef struct {
    char *name;
    StructMember *members;
    int member_count;
    int total_size;
} StructType;
```

### 困难与解决

**问题**：成员偏移计算和对齐  
**解决**：按成员大小累加偏移，考虑对齐要求

## 6. 初始化与多变量定义

### 实现思路

**语法规则**：

```yacc
declaration
    : type_specifier init_declarator_list ';'
    ;

init_declarator_list
    : init_declarator
    | init_declarator_list ',' init_declarator
    ;

init_declarator
    : ID
    | ID '=' expression
    ;
```

**示例**：

```c
int a = 10, b, c = 20;
```

**中间代码**：

```
a = 10
c = 20
```

### 困难与解决

**问题**：多个变量共享类型说明符  
**解决**：在规约时遍历声明列表，逐个处理

## 7. 混合运算与优先级

### 实现思路

**优先级定义**：

```yacc
%right '='
%left OR
%left AND
%left EQ NE
%left '<' '>' LE GE
%left '+' '-'
%left '*' '/' '%'
%right '!' UMINUS
```

**类型提升**：

```c
if (left_type == INT && right_type == FLOAT) {
    // 将 int 转换为 float
    insert_conversion(left, TYPE_FLOAT);
}
```

### 困难与解决

**问题**：移进-归约冲突  
**解决**：明确优先级和结合性

## 8. 注释支持

### 实现思路

**词法规则**：

```flex

"//".*\n    { yylineno++; }
```

### 困难与解决

## 9. 格式化输出

### 实现思路

**内置函数**：

```c
output_int(int x);    // 输出整数
output_float(float x); // 输出浮点数
```

**汇编实现**：

```nasm
; output_int
mov edi, [rbp-8]
lea rsi, [rel fmt_int]   ; "%d\n"
xor eax, eax
call printf

; output_float
movss xmm0, [rbp-8]
cvtss2sd xmm0, xmm0      ; 转换为 double
lea rdi, [rel fmt_float] ; "%.2f\n"
mov eax, 1
call printf
```

### 困难与解决

**问题**：printf 可变参数需要指定浮点参数数量  
**解决**：设置 eax 为浮点参数数量

## 10. 控制流 If/Else/Loop

### 实现思路

**If-Else**：

```
    计算条件
    if 条件 goto THEN_LABEL
    goto ELSE_LABEL
THEN_LABEL:
    then 分支
    goto END_LABEL
ELSE_LABEL:
    else 分支
END_LABEL:
```

**While 循环**：

```
START_LABEL:
    计算条件
    if 条件 goto BODY_LABEL
    goto END_LABEL
BODY_LABEL:
    循环体
    goto START_LABEL
END_LABEL:
```

**For 循环**：

```
    初始化语句
START_LABEL:
    计算条件
    if 条件 goto BODY_LABEL
    goto END_LABEL
BODY_LABEL:
    循环体
    更新表达式
    goto START_LABEL
END_LABEL:
```

### 困难与解决

**问题**：行号跳转不正确  
**解决**：使用符号标签系统，代码生成后统一替换
