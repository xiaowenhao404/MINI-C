## 概述

**对应文件**: `src/frontend/lex.l`, `src/frontend/yacc.y`

### 整体流程

```
源代码 (.c)
    ↓
词法分析 (Flex) → Token 序列 → Lexical 文件
    ↓
语法分析 (Bison) → 抽象语法树 (AST) → Grammatical 文件
    ↓
后续阶段（语义分析、IR生成等）
```

### 工具选择

| 工具 | 用途 | 优势 |
|------|------|------|
| **Flex** | 词法分析器生成器 | 基于正则表达式，高效匹配 |
| **Bison** | 语法分析器生成器 | 支持 LALR(1) 文法，自动处理优先级 |

## 词法分析

### 核心思路

将源代码字符流转换为 Token 序列，每个 Token 包含类型和值。

### Token 类型定义

#### 关键字

```flex
"void"      { return VOID; }
"int"       { return INT; }
"float"     { return FLOAT; }
"char"      { return CHAR; }
"if"        { return IF; }
"else"      { return ELSE; }
"while"     { return WHILE; }
"for"       { return FOR; }
"return"    { return RETURN; }
"break"     { return BREAK; }
"continue"  { return CONTINUE; }
"struct"    { return STRUCT; }
```

#### 标识符

```flex
{LETTER}({LETTER}|{DIGIT})*   { 
    yylval.strval = strdup(yytext);
    return ID; 
}
```

- `LETTER`: `[a-zA-Z_]`
- `DIGIT`: `[0-9]`

#### 常量

```flex
{DIGIT}+                { yylval.ival = atoi(yytext); return INT_NUM; }
{DIGIT}+"."{DIGIT}+     { yylval.fval = atof(yytext); return FLOAT_NUM; }
```

#### 运算符

```flex
"+"     { return '+'; }
"-"     { return '-'; }
"*"     { return '*'; }
"/"     { return '/'; }
"%"     { return '%'; }
"<"     { return '<'; }
">"     { return '>'; }
"<="    { return LE; }
">="    { return GE; }
"=="    { return EQ; }
"!="    { return NE; }
"&&"    { return AND; }
"||"    { return OR; }
"!"     { return '!'; }
"="     { return '='; }
```

### 注释处理

```flex
"//".*\n                { /* 单行注释，忽略 */ }
"/*"([^*]|\*+[^*/])*\*+"/"  { /* 多行注释，忽略 */ }
```

### 空白字符处理

```flex
[ \t\r]+    { /* 忽略空格和制表符 */ }
\n          { yylineno++; /* 换行时更新行号 */ }
```

## 语法分析

### 核心思路

使用 Bison 定义文法规则，将 Token 序列组织成抽象语法树（AST）。

### 文法设计

#### 程序结构

```yacc
program
    : external_declaration_list
    ;

external_declaration_list
    : external_declaration
    | external_declaration_list external_declaration
    ;

external_declaration
    : function_definition
    | declaration
    ;
```

#### 函数定义

```yacc
function_definition
    : type_specifier ID '(' ')' compound_statement
    | type_specifier ID '(' parameter_list ')' compound_statement
    ;

parameter_list
    : parameter_declaration
    | parameter_list ',' parameter_declaration
    ;

parameter_declaration
    : type_specifier ID
    ;
```

#### 语句

```yacc
statement
    : expression_statement
    | compound_statement
    | selection_statement
    | iteration_statement
    | jump_statement
    | declaration
    ;

compound_statement
    : '{' '}'
    | '{' statement_list '}'
    ;

selection_statement
    : IF '(' expression ')' statement
    | IF '(' expression ')' statement ELSE statement
    ;

iteration_statement
    : WHILE '(' expression ')' statement
    | FOR '(' expression_statement expression_statement expression ')' statement
    ;
```

#### 表达式

```yacc
expression
    : assignment_expression
    ;

assignment_expression
    : logical_or_expression
    | unary_expression '=' assignment_expression
    ;

logical_or_expression
    : logical_and_expression
    | logical_or_expression OR logical_and_expression
    ;

/* ... 其他表达式规则 ... */

primary_expression
    : ID
    | constant
    | '(' expression ')'
    ;
```

### 优先级与结合性

```yacc
/* 从低到高 */
%right '='
%left OR
%left AND
%left EQ NE
%left '<' '>' LE GE
%left '+' '-'
%left '*' '/' '%'
%right '!' UMINUS
%left '[' '(' '.'
```

### AST 构建

在每个产生式后添加语义动作，构建 AST 节点：

```yacc
additive_expression
    : multiplicative_expression
        { $$ = $1; }
    | additive_expression '+' multiplicative_expression
        { $$ = createTree("ADD", 2, $1, $3); }
    | additive_expression '-' multiplicative_expression
        { $$ = createTree("SUB", 2, $1, $3); }
    ;
```

## 遇到的困难与解决方法

### 问题 1：关键字与标识符冲突

**问题描述**：
`integer` 被错误识别为 `int` + `eger`。

**解决方案**：
- 关键字规则放在标识符规则之前
- Flex 最长匹配原则确保正确匹配

```flex
/* 关键字在前 */
"int"       { return INT; }

/* 标识符在后 */
{LETTER}({LETTER}|{DIGIT})*   { return ID; }
```

### 问题 2：悬垂 else 问题

**问题描述**：
嵌套的 if-else 语句有歧义，不知道 else 属于哪个 if。

```c
if (a) if (b) x = 1; else y = 2;  // else 属于哪个 if？
```

**解决方案**：
使用 Bison 的优先级机制，让 else 总是与最近的 if 匹配：

```yacc
%nonassoc IF
%nonassoc ELSE

selection_statement
    : IF '(' expression ')' statement %prec IF
    | IF '(' expression ')' statement ELSE statement
    ;
```

### 问题 3：移进-归约冲突

**问题描述**：
Bison 报告移进-归约冲突，表达式解析不正确。

**解决方案**：
- 明确定义运算符优先级和结合性
- 使用 `%prec` 处理特殊情况（如一元负号）

```yacc
%left '+' '-'
%left '*' '/'
%right UMINUS

unary_expression
    : '-' unary_expression %prec UMINUS
        { $$ = createTree("NEG", 1, $2); }
    ;
```

### 问题 4：错误恢复

**问题描述**：
语法错误时编译器直接终止，无法继续分析后续代码。

**解决方案**：
使用 Bison 的 `error` 产生式进行错误恢复：

```yacc
statement
    : expression_statement
    | compound_statement
    | error ';'  /* 错误恢复：跳到下一个分号 */
        { yyerror("语法错误"); yyerrok; }
    ;
```

### 问题 5：行号跟踪

**问题描述**：
错误信息需要显示行号，但解析过程中行号信息丢失。

**解决方案**：
- Flex 中启用 `yylineno`
- AST 节点保存行号信息

```flex
%option yylineno

/* ... */

{LETTER}({LETTER}|{DIGIT})*   { 
    yylval.tree = createNode(ID, yylineno);
    return ID; 
}
```
