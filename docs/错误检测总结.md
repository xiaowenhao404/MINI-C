## 错误输出格式

### 统一格式

```
[错误类型] 行 X: [错误子类] 具体描述
```

### 格式示例

```
[词法错误] 注释未闭合，缺少结束符 */
[语法错误] 行 5: 可能缺少分号
[语义错误] 行 10: [变量未定义] 变量 'x' 未声明
[语义错误] 行 15: [类型不匹配] 不能将 'float' 赋值给 'int*'
```

### 编译阶段提示

```
=== 编译阶段 ===
🔍 开始词法和语法分析...
✓ 词法和语法分析成功！

🔍 开始语义分析...
[语义错误] 行 3: [变量未定义] 变量 'c' 未声明
❌ 语义分析失败！发现 1 个语义错误

=== 编译终止 ===
```

## 各类错误检测详解

### 1. 词法错误

#### 1.1 注释未闭合

**检测条件**: 多行注释 `/*` 没有对应的 `*/` 结束符

**输出格式**:
```
[词法错误] 注释未闭合，缺少结束符 */
```

#### 1.2 非法字符

**检测条件**: 出现不在语言定义中的字符

**输出格式**:
```
[词法错误] 行 X: 非法字符 'X'
```

#### 1.3 字符串未闭合

**检测条件**: 字符串字面量没有结束引号

**输出格式**:
```
[词法错误] 行 X: 字符串未闭合
```

---

### 2. 语法错误

#### 2.1 缺少分号

**检测条件**: 语句结尾缺少分号

**输出格式**:
```
[语法错误] 行 X: 可能缺少分号
```

#### 2.2 括号不匹配

**检测条件**: 圆括号、方括号或花括号不匹配

**输出格式**:
```
[语法错误] 行 X: 括号不匹配，可能缺少 ')'
[语法错误] 行 X: 括号不匹配，可能缺少 '}'
[语法错误] 行 X: 括号不匹配，可能缺少 ']'
```

#### 2.3 语句结构不完整

**检测条件**: 控制结构语法不完整

**输出格式**:
```
[语法错误] 行 X: 语句结构不完整，意外的标识符 'xxx'
[语法错误] 行 X: if 语句缺少条件表达式
[语法错误] 行 X: while 语句缺少循环体
```

---

### 3. 语义错误

#### 3.1 变量相关

##### 变量未声明

**检测条件**: 使用未声明的变量

**输出格式**:
```
[语义错误] 行 X: [变量未定义] 变量 'name' 未声明
```

##### 变量重定义

**检测条件**: 同一作用域内重复声明同名变量

**输出格式**:
```
[语义错误] 行 X: [重定义] 变量 'name' 重复定义
```

##### 作用域错误

**检测条件**: 访问超出作用域的变量

**输出格式**:
```
[语义错误] 行 X: [变量未定义] 变量 'name' 未声明
```

---

#### 3.2 类型相关

##### 类型不匹配

**检测条件**: 赋值或运算时类型不兼容

**输出格式**:
```
[语义错误] 行 X: [类型不匹配] 不能将 'type1' 赋值给 'type2'
```

##### 非左值赋值

**检测条件**: 赋值运算符左侧不是左值

**输出格式**:
```
[语义错误] 行 X: [非左值赋值] 赋值运算的左侧必须是左值
```

---

#### 3.3 数组相关

##### 数组下标类型错误

**检测条件**: 数组下标不是整数类型

**输出格式**:
```
[语义错误] 行 X: [下标类型] 数组下标必须是整数类型
```

##### 非数组使用下标

**检测条件**: 对非数组变量使用下标访问

**输出格式**:
```
[语义错误] 行 X: [类型错误] 'name' 不是数组
```

##### 数组重定义

**检测条件**: 同一作用域内重复声明同名数组

**输出格式**:
```
[语义错误] 行 X: [重定义] 数组 'name' 重复定义
```

---

#### 3.4 指针相关

##### 非法解引用

**检测条件**: 对非指针类型进行解引用操作

**输出格式**:
```
[语义错误] 行 X: [解引用] 不能对非指针类型解引用
```

##### 指针重定义

**检测条件**: 同一作用域内重复声明同名指针

**输出格式**:
```
[语义错误] 行 X: [重定义] 指针变量 'name' 重复定义
```

---

#### 3.5 函数相关

##### 参数数量不匹配

**检测条件**: 函数调用时参数数量与定义不符

**输出格式**:
```
[语义错误] 行 X: [参数数量] 函数 'name' 参数数量不匹配, 期望 N 个, 实际 M 个
```

##### 返回类型不匹配

**检测条件**: 返回语句的类型与函数声明不符

**输出格式**:
```
[语义错误] 行 X: [返回类型] 函数应返回 'type' 类型的值
[语义错误] 行 X: [返回类型] void 函数不应返回值
```

##### 函数未定义

**检测条件**: 调用未定义的函数

**输出格式**:
```
[语义错误] 行 X: [函数未定义] 函数 'name' 未定义
```
