## 概述

**对应文件**: `src/semantic/type_system.c`, `src/semantic/symbol_table.c`, `src/semantic/semantic_analyzer.c`

### 整体流程

```
AST (抽象语法树)
    ↓
符号表构建
    ↓
类型推导
    ↓
类型兼容性检查
    ↓
类型转换节点插入
    ↓
类型正确的 AST
```

### 设计目标

1. **类型安全**：在编译期发现类型错误
2. **隐式转换**：支持合理的自动类型转换
3. **清晰报错**：提供有意义的错误信息

## 类型系统设计

### 基本类型

| 类型 | 大小 | 说明 |
|------|------|------|
| `TYPE_INT` | 4 字节 | 32 位有符号整数 |
| `TYPE_FLOAT` | 4 字节 | 32 位浮点数 |
| `TYPE_CHAR` | 1 字节 | 8 位字符 |
| `TYPE_VOID` | - | 空类型 |

### 复合类型

#### 指针类型

```c
typedef struct Type {
    enum TypeKind kind;
    struct Type *base_type;  // 指针指向的类型
} Type;

// int* → kind=TYPE_POINTER, base_type->kind=TYPE_INT
```

#### 数组类型

```c
typedef struct Type {
    enum TypeKind kind;
    struct Type *elem_type;  // 元素类型
    int size;                // 数组大小
} Type;

// int[10] → kind=TYPE_ARRAY, elem_type->kind=TYPE_INT, size=10
```

#### 函数类型

```c
typedef struct Type {
    enum TypeKind kind;
    struct Type *return_type;   // 返回类型
    struct Type **param_types;  // 参数类型列表
    int param_count;            // 参数数量
} Type;
```

### 类型表示

```c
typedef struct Type {
    enum TypeKind kind;  // TYPE_INT, TYPE_FLOAT, TYPE_POINTER, ...
    union {
        struct Type *base_type;    // 指针基类型
        struct {
            struct Type *elem_type;
            int size;
        } array;                   // 数组信息
        struct {
            struct Type *return_type;
            struct Type **param_types;
            int param_count;
        } func;                    // 函数信息
    };
} Type;
```

## 符号表结构

### 符号定义

```c
typedef struct Symbol {
    char *name;           // 标识符名称
    Type *type;           // 类型信息
    int scope_level;      // 作用域层级
    int offset;           // 栈偏移（用于代码生成）
    enum SymbolKind kind; // SYMBOL_VAR, SYMBOL_FUNC, SYMBOL_PARAM
    int line;             // 声明位置
} Symbol;
```

### 符号表

```c
typedef struct SymbolTable {
    HashMap *symbols;           // 当前作用域的符号
    struct SymbolTable *parent; // 父作用域
    int level;                  // 作用域层级
} SymbolTable;
```

### 作用域管理

```c
// 进入新作用域
void enter_scope(SymbolTable **table) {
    SymbolTable *new_table = create_symbol_table();
    new_table->parent = *table;
    new_table->level = (*table)->level + 1;
    *table = new_table;
}

// 退出当前作用域
void exit_scope(SymbolTable **table) {
    SymbolTable *old = *table;
    *table = old->parent;
    free_symbol_table(old);
}

// 查找符号（逐层向上）
Symbol* lookup(SymbolTable *table, const char *name) {
    while (table) {
        Symbol *sym = hashmap_get(table->symbols, name);
        if (sym) return sym;
        table = table->parent;
    }
    return NULL;
}
```

## 类型检查规则

### 类型兼容性

#### 赋值兼容性

```c
bool is_assignable(Type *lhs, Type *rhs) {
    // 相同类型
    if (types_equal(lhs, rhs)) return true;
    
    // int → float
    if (lhs->kind == TYPE_FLOAT && rhs->kind == TYPE_INT)
        return true;
    
    // 数组 → 指针（退化）
    if (lhs->kind == TYPE_POINTER && rhs->kind == TYPE_ARRAY)
        return types_equal(lhs->base_type, rhs->elem_type);
    
    return false;
}
```

#### 运算兼容性

```c
Type* get_binary_result_type(Type *left, Type *right, char op) {
    // 算术运算
    if (op == '+' || op == '-' || op == '*' || op == '/') {
        if (left->kind == TYPE_FLOAT || right->kind == TYPE_FLOAT)
            return create_type(TYPE_FLOAT);
        return create_type(TYPE_INT);
    }
    
    // 比较运算 → 结果为 int
    if (op == '<' || op == '>' || op == EQ || op == NE)
        return create_type(TYPE_INT);
    
    return NULL;  // 不兼容
}
```

### 隐式类型转换

```c
void insert_type_conversion(AST *node, Type *target) {
    if (node->type->kind == TYPE_INT && target->kind == TYPE_FLOAT) {
        // 插入 i2f 转换节点
        AST *conv = create_node("I2F", 1, node);
        conv->type = create_type(TYPE_FLOAT);
        // 替换原节点
    }
}
```

### 表达式类型推导

```c
void infer_expression_type(AST *expr) {
    switch (expr->kind) {
        case AST_INT_LITERAL:
            expr->type = create_type(TYPE_INT);
            break;
            
        case AST_FLOAT_LITERAL:
            expr->type = create_type(TYPE_FLOAT);
            break;
            
        case AST_IDENTIFIER:
            Symbol *sym = lookup(current_scope, expr->name);
            if (sym) expr->type = sym->type;
            else report_error("变量未定义");
            break;
            
        case AST_BINARY_OP:
            infer_expression_type(expr->left);
            infer_expression_type(expr->right);
            expr->type = get_binary_result_type(
                expr->left->type, expr->right->type, expr->op);
            break;
            
        case AST_ARRAY_ACCESS:
            infer_expression_type(expr->array);
            infer_expression_type(expr->index);
            if (expr->array->type->kind == TYPE_ARRAY)
                expr->type = expr->array->type->elem_type;
            break;
            
        case AST_DEREF:
            infer_expression_type(expr->operand);
            if (expr->operand->type->kind == TYPE_POINTER)
                expr->type = expr->operand->type->base_type;
            break;
    }
}
```

## 遇到的困难与解决方法

### 问题 1：作用域管理复杂

**问题描述**：
多层嵌套作用域中，变量查找和重定义检测逻辑复杂。

**解决方案**：
- 使用链式符号表结构
- 每个作用域维护独立的符号映射
- 查找时逐层向上搜索

```c
// 当前作用域重定义检查
Symbol *existing = hashmap_get(current_scope->symbols, name);
if (existing) {
    report_error("变量重定义");
}

// 全局查找（允许遮蔽）
Symbol *sym = lookup(current_scope, name);
```

### 问题 2：类型推导与转换

**问题描述**：
混合类型表达式需要正确推导结果类型并插入转换节点。

**解决方案**：
- 自底向上推导类型
- 运算前检查操作数类型
- 必要时插入转换节点

```c
// int + float → float
if (left->type->kind == TYPE_INT && right->type->kind == TYPE_FLOAT) {
    insert_type_conversion(left, TYPE_FLOAT);  // 插入 i2f
}
```

### 问题 3：数组和指针关系

**问题描述**：
数组可以退化为指针，但数组和指针本质不同。

**解决方案**：
- 明确区分 TYPE_ARRAY 和 TYPE_POINTER
- 数组名在表达式中退化为指针
- 保留数组大小信息用于边界检查（可选）

### 问题 4：函数参数类型匹配

**问题描述**：
函数调用时需要检查参数数量和类型。

**解决方案**：

```c
void check_function_call(AST *call, Symbol *func) {
    // 检查参数数量
    if (call->arg_count != func->type->param_count) {
        report_error("参数数量不匹配");
        return;
    }
    
    // 检查每个参数类型
    for (int i = 0; i < call->arg_count; i++) {
        Type *actual = call->args[i]->type;
        Type *expected = func->type->param_types[i];
        
        if (!is_assignable(expected, actual)) {
            report_error("参数类型不匹配");
        }
    }
}
```
