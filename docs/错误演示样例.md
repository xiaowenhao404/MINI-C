## 1. 词法错误

### 1.1 未闭合注释

**测试代码** (复制到 test_error.c):

```c
void main() {
    int a = 10;
    /* 这是一个未闭合的注释
    output_int(a);
}
```

**预期输出**:

```
=== 编译阶段 ===
🔍 开始词法和语法分析...
[词法错误] 注释未闭合，缺少结束符 */

❌ 词法分析失败！发现 1 个词法错误
=== 编译终止 ===
```

## 2. 语法错误

### 2.1 缺少分号

**测试代码** (复制到 test_error.c):

```c
void main() {
    int a = 10
    int b = 20;
    output_int(a);
}
```

**预期输出**:

```
[语法错误] 行 2: 可能缺少分号
```

---

### 2.2 括号不匹配

**测试代码** (复制到 test_error.c):

```c
void main() {
    int a = 10;
    if (a > 5 {
        output_int(a);
    }
}
```

**预期输出**:

```
[语法错误] 行 3: 括号不匹配，可能缺少 ')'
```

---

### 2.3 语句结构错误

**测试代码** (复制到 test_error.c):

```c
void main() {
    int a = 10;
    if
        output_int(a);
}
```

**预期输出**:

```
[语法错误] 行 4: 语句结构不完整，意外的标识符 'output_int'
```

## 3. 变量相关错误

### 3.1 变量未声明

**测试代码** (复制到 test_error.c):

```c
void main() {
    int a = 10;
    int b = c + 5;
    output_int(b);
}
```

**预期输出**:

```
[语义错误] 行 3: [变量未定义] 变量 'c' 未声明
```

---

### 3.2 变量重定义

**测试代码** (复制到 test_error.c):

```c
void main() {
    int x = 10;
    int x = 20;
    output_int(x);
}
```

**预期输出**:

```
[语义错误] 行 4: [重定义] 变量 'x' 重复定义
```

---

### 3.3 作用域错误

**测试代码** (复制到 test_error.c):

```c
void main() {
    {
        int local = 10;
    }
    int a = local + 5;
    output_int(a);
}
```

**预期输出**:

```
[语义错误] 行 5: [变量未定义] 变量 'local' 未声明
```

## 4. 类型相关错误

### 4.1 赋值类型不匹配

**测试代码** (复制到 test_error.c):

```c
void main() {
    int x = 10;
    int* ptr;
    ptr = &x;
    x = ptr;
    output_int(x);
}
```

**预期输出**:

```
[语义错误] 行 5: [类型不匹配] 不能将 'pointer' 赋值给 'int'
```

---

### 4.2 非左值赋值

**测试代码** (复制到 test_error.c):

```c
void main() {
    int a = 10;
    int b = 20;
    (a + b) = 30;
    output_int(a);
}
```

**预期输出**:

```
[语义错误] 行 4: [非左值赋值] 赋值运算的左侧必须是左值
```

---

## 5. 数组相关错误

### 5.1 数组下标类型错误

**测试代码** (复制到 test_error.c):

```c
void main() {
    int arr[10];
    float idx = 2.5;
    int val = arr[idx];
    output_int(val);
}
```

**预期输出**:

```
[语义错误] 行 5: [下标类型] 数组下标必须是整数类型
```

---

### 5.2 非数组变量使用下标

**测试代码** (复制到 test_error.c):

```c
void main() {
    int x = 10;
    int val = x[0];
    output_int(val);
}
```

**预期输出**:

```
[语义错误] 行 3: [类型错误] 'x' 不是数组
```

---

### 5.3 数组重定义

**测试代码** (复制到 test_error.c):

```c
void main() {
    int arr[10];
    int arr[5];
    output_int(arr[0]);
}
```

**预期输出**:

```
[语义错误] 行 3: [重定义] 数组 'arr' 重复定义
```

## 7. 函数相关错误

### 7.1 函数参数数量不匹配

**测试代码** (复制到 test_error.c):

```c
int add(int a, int b) {
    return a + b;
}

void main() {
    int result = add(10);
    output_int(result);
}
```

**预期输出**:

```
[语义错误] 行 6: [参数数量] 函数 'add' 参数数量不匹配, 期望 2 个, 实际 1 个
```

---

### 7.2 返回类型不匹配

**注意**: int 和 float 之间可以隐式转换，因此不会报错。下面测试函数声明为非 void 但没有返回值的情况：

**测试代码** (复制到 test_error.c):

```c
int get_value() {
    int x = 10;
    return;
}

void main() {
    int result = get_value();
    output_int(result);
}
```

**预期输出**:

```
[语义错误] 行 3: [返回类型] 函数应返回 'int' 类型的值
```

---

### 7.3 void 函数返回值

**测试代码** (复制到 test_error.c):

```c
void print_hello() {
    output_int(100);
    return 42;
}

void main() {
    print_hello();
}
```

**预期输出**:

```
[语义错误] 行 3: [返回类型] void 函数不应返回值
```
