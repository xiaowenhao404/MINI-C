## 概述

**对应文件**: `scripts/asm_generator.py`

汇编代码生成器负责将中间代码（Innercode 三地址码）翻译为 x86-64 NASM 汇编代码。

### 功能特性

| 功能 | 说明 |
|------|------|
| 整数运算 | `+`, `-`, `*`, `/`, `%` 使用 `eax`, `ebx` |
| 浮点运算 | `f+`, `f-`, `f*`, `f/` 使用 SSE 指令 |
| 内存操作 | `alloc`, `addr`, `load`, `store` |
| 控制流 | 标签跳转、条件判断 |
| 函数调用 | System V ABI 调用约定 |

## 生成器架构

### 整体流程

```
Innercode (三地址码)
    ↓
解析四元式
    ↓
变量偏移分配
    ↓
标签映射建立
    ↓
指令翻译
    ↓
assembly.asm (x86-64)
```

### 核心数据结构

```python
# 变量到栈偏移的映射
var_offsets = {}  # 例如: {'a': -8, 'b': -16}

# 变量类型信息
var_types = {}    # 例如: {'a': 'int', 'x': 'float'}

# 标签映射（IR行号 → 汇编标签）
label_map = {}    # 例如: {5: 'CODE1', 10: 'CODE2'}
```

## 核心实现思路

### 1. 变量分配

每个变量分配 8 字节栈空间（统一处理 64 位地址和 32 位整数）：

```python
offset = 8 * data.index(var_name) + 8
# 变量访问：[rbp-offset]
```

### 2. 寄存器约定

| 寄存器 | 用途 |
|--------|------|
| `rax/eax` | 第一操作数、运算结果、返回值、64 位地址 |
| `rbx/ebx` | 第二操作数 |
| `xmm0` | 第一浮点操作数、运算结果 |
| `xmm1` | 第二浮点操作数 |
| `rdi` | 函数第一参数（System V ABI） |

### 3. 栈帧布局

```
rbp+0    ← 保存的 rbp
rbp-8    ← 第 1 个变量
rbp-16   ← 第 2 个变量
rbp-24   ← 第 3 个变量
...
rbp-1024 ← 栈底
```

## 指令翻译规则

### 整数运算

```python
# 中间代码: t = a + b
# 汇编:
mov eax, [rbp-8]      # 加载 a
mov ebx, [rbp-16]     # 加载 b
add eax, ebx          # 计算
mov [rbp-24], eax     # 存储结果 t
```

### 浮点运算

```python
# 中间代码: t = x f+ y
# 汇编:
movss xmm0, [rbp-8]   # 加载 x
movss xmm1, [rbp-16]  # 加载 y
addss xmm0, xmm1      # 计算
movss [rbp-24], xmm0  # 存储结果 t
```

### 地址操作

```python
# 中间代码: t = addr val
# 汇编:
lea rax, [rbp-8]      # 获取 val 的地址
mov [rbp-16], rax     # 存储到 t（64位）

# 中间代码: t = load ptr
# 汇编:
mov rax, [rbp-16]     # 加载指针值
mov eax, [rax]        # 解引用
mov [rbp-24], eax     # 存储结果

# 中间代码: store val ptr
# 汇编:
mov ebx, [rbp-8]      # 加载要存储的值
mov rax, [rbp-16]     # 加载目标地址
mov [rax], ebx        # 存储到内存
```

### 函数调用

```python
# 整数输出
mov eax, [rbp-8]          # 加载参数
mov edi, eax              # 第一参数
lea rsi, [rel fmt_int]    # 格式串
xor eax, eax              # 浮点参数数量 = 0
call printf

# 浮点输出
movss xmm0, [rbp-8]       # 加载浮点参数
cvtss2sd xmm0, xmm0       # 转换为 double
lea rdi, [rel fmt_float]
mov eax, 1                # 浮点参数数量 = 1
call printf
```

## 遇到的困难与解决方法

### 问题 1：汇编标签映射与索引偏移错误

**问题描述**：
中间代码使用行号作为跳转目标，汇编中使用标签。需要建立从行号到标签的映射。

**现象**：
- `nasm` 报错：`symbol 'CODE12' not defined`
- 或 `symbol 'END_PROGRAM' not defined`

**原因分析**：
- 标签映射使用了错误的下标（1-based vs 0-based 混用）
- `if/goto` 处理时，对目标行号的索引计算有误

**解决方案**：

1. 明确约定：
   - 中间代码行号：1-based
   - Python 列表下标：0-based
   - 转换公式：`index = line_number - 1`

2. 修正标签映射：

```python
# 预处理：收集所有跳转目标
label_map = {}
label_counter = 1
for i, instr in enumerate(ir_instructions):
    if instr[0] in ['if', 'goto']:
        target_line = int(instr[3])
        if target_line not in label_map:
            label_map[target_line] = f'CODE{label_counter}'
            label_counter += 1
```

### 问题 2：`NoneType` 拼接与 `_` 占位符处理

**问题描述**：
中间代码某些字段为 `_`（占位符）或 `None`，汇编生成时直接使用导致错误。

**现象**：
- `TypeError: can only concatenate str (not "NoneType") to str`

**解决方案**：

```python
def get_var_offset(var_name):
    if var_name == '_' or var_name is None:
        return None
    if var_name not in var_offsets:
        raise ValueError(f"Variable {var_name} not found")
    return var_offsets[var_name]
```

### 问题 3：浮点数输出错误

**问题描述**：
浮点数显示不正确。

**原因分析**：
x86-64 的 printf 需要 double 参数，而我们使用的是 float。

**解决方案**：
使用 `cvtss2sd` 转换：

```nasm
movss xmm0, [rbp-8]       ; 加载 float
cvtss2sd xmm0, xmm0       ; 转换为 double
```

### 问题 4：栈帧溢出

**问题描述**：
运行时 Segmentation fault，或输出垃圾值。

**原因分析**：
- 变量偏移从 4 字节改为 8 字节
- 最大偏移量从 ~200 增加到 ~460
- 栈帧仍是 144 字节

**解决方案**：

```python
# 扩展栈帧
result += [tab + "sub rsp, 1024"]
```

### 问题 5：64 位地址处理错误

**问题描述**：
原始代码使用 32 位寄存器处理指针地址，导致地址截断。

**解决方案**：

```python
# 指针操作使用 64 位寄存器
if is_pointer:
    result += [tab + f"mov rax, [rbp-{src_offset}]"]  # 64位
    result += [tab + f"mov [rbp-{offset}], rax"]
else:
    result += [tab + f"mov eax, [rbp-{src_offset}]"]  # 32位
    result += [tab + f"mov [rbp-{offset}], eax"]
```
