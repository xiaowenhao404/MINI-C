## 常量折叠

### 原理

在编译期计算所有常量表达式，将结果直接替换到代码中。

### 优化效果

```c
// 优化前
int result = 3 + 4 * 5;

// 优化后
int result = 23;
```

### 实现思路

```c
AST* fold_constants(AST *node) {
    if (node == NULL) return NULL;
    
    // 递归处理子节点
    for (int i = 0; i < node->child_count; i++) {
        node->children[i] = fold_constants(node->children[i]);
    }
    
    // 检查是否可以折叠
    if (is_binary_op(node) && 
        is_constant(node->left) && 
        is_constant(node->right)) {
        
        int result = evaluate(node->op, 
                              get_value(node->left), 
                              get_value(node->right));
        
        return create_constant_node(result);
    }
    
    return node;
}
```

### 支持的运算

| 运算 | 示例 | 结果 |
|------|------|------|
| 算术 | `3 + 4 * 5` | `23` |
| 逻辑 | `1 && 0` | `0` |
| 比较 | `5 > 3` | `1` |

### 安全检查

```c
// 除零检查
if (op == '/' && right_value == 0) {
    report_warning("除零错误");
    return node;  // 不折叠
}
```

## 死代码消除

### 原理

识别并移除永远不会执行的代码块。

### 优化效果

```c
// 优化前
if (0) {
    x = 10;  // 永远不执行
}

// 优化后
// （整个 if 语句被删除）
```

### 实现思路

```c
AST* eliminate_dead_code(AST *node) {
    if (node == NULL) return NULL;
    
    // 处理 if 语句
    if (node->kind == AST_IF) {
        if (is_constant_zero(node->condition)) {
            // if (0) → 删除 then 分支
            return node->else_branch;  // 可能为 NULL
        }
        if (is_constant_nonzero(node->condition)) {
            // if (1) → 只保留 then 分支
            return node->then_branch;
        }
    }
    
    // 处理 while 语句
    if (node->kind == AST_WHILE) {
        if (is_constant_zero(node->condition)) {
            // while (0) → 删除整个循环
            return NULL;
        }
    }
    
    // 递归处理子节点
    for (int i = 0; i < node->child_count; i++) {
        node->children[i] = eliminate_dead_code(node->children[i]);
    }
    
    return node;
}
```

### 检测模式

| 模式 | 处理方式 |
|------|----------|
| `if (0) { A } else { B }` | 只保留 B |
| `if (1) { A } else { B }` | 只保留 A |
| `if (0) { A }` | 删除整个语句 |
| `while (0) { A }` | 删除整个循环 |

## 活性分析

### 原理

活性分析（Liveness Analysis）确定程序中每个变量在哪些位置是"活跃"的（即其值将来会被使用）。

### 理论基础

#### 数据流方程

```
USE[B]：基本块 B 中使用但未先定义的变量集合
DEF[B]：基本块 B 中定义的变量集合

LIVE_OUT[B] = ∪ LIVE_IN[S]  (对所有 B 的后继 S)
LIVE_IN[B] = USE[B] ∪ (LIVE_OUT[B] - DEF[B])
```

#### 迭代算法

```
初始化：所有 LIVE_IN 和 LIVE_OUT 为空集

repeat
    changed = false
    for each block B (逆序):
        old_in = LIVE_IN[B]
        
        LIVE_OUT[B] = ∪ LIVE_IN[successor]
        LIVE_IN[B] = USE[B] ∪ (LIVE_OUT[B] - DEF[B])
        
        if LIVE_IN[B] ≠ old_in:
            changed = true
until not changed
```

#### 步骤 2：计算 USE 和 DEF

```c
void compute_use_def(BasicBlock *block) {
    block->use = create_set();
    block->def = create_set();
    
    for (Instruction *inst = block->first; inst; inst = inst->next) {
        // 使用的变量（如果未在本块中定义）
        for (each operand in inst) {
            if (is_variable(operand) && !set_contains(block->def, operand)) {
                set_add(block->use, operand);
            }
        }
        
        // 定义的变量
        if (inst->has_result) {
            set_add(block->def, inst->result);
        }
    }
}
```

#### 步骤 3：迭代求解

```c
void solve_liveness(CFG *cfg) {
    bool changed;
    
    do {
        changed = false;
        
        // 逆序遍历（后向分析）
        for (int i = cfg->block_count - 1; i >= 0; i--) {
            BasicBlock *B = cfg->blocks[i];
            Set *old_in = set_copy(B->live_in);
            
            // LIVE_OUT[B] = ∪ LIVE_IN[successor]
            set_clear(B->live_out);
            for (each successor S of B) {
                set_union(B->live_out, S->live_in);
            }
            
            // LIVE_IN[B] = USE[B] ∪ (LIVE_OUT[B] - DEF[B])
            set_copy_to(B->live_in, B->live_out);
            set_difference(B->live_in, B->def);
            set_union(B->live_in, B->use);
            
            if (!set_equals(B->live_in, old_in)) {
                changed = true;
            }
        }
    } while (changed);
}
```

### 应用场景

1. **寄存器分配**：只有活跃变量需要保留在寄存器中
2. **死代码消除**：如果变量赋值后不再活跃，该赋值可以删除
3. **栈槽复用**：生命周期不重叠的变量可以共享栈空间

## 遇到的困难与解决方法

### 问题 1：常量折叠的边界情况

**问题描述**：
除零、浮点混合运算、副作用表达式需要特殊处理。

**解决方案**：
- 除零检查，不折叠
- 区分整型和浮点运算
- 只对纯表达式折叠

### 问题 2：活性分析的循环处理

**问题描述**：
循环引入后向边，信息需要多次传播才能收敛。

**解决方案**：
- 迭代直到不动点
- 理论保证收敛（单调框架 + 有限格）

### 问题 3：集合操作效率

**问题描述**：
频繁的集合并、交、差运算影响性能。

**解决方案**：
使用位向量表示变量集合：

```c
typedef unsigned long BitVector;

void set_union(BitVector *a, BitVector b) {
    *a |= b;
}

void set_difference(BitVector *a, BitVector b) {
    *a &= ~b;
}

bool set_equals(BitVector a, BitVector b) {
    return a == b;
}
```

### 问题 4：CFG 构建

**问题描述**：
从线性 IR 构建 CFG 需要识别基本块边界和跳转目标。

**解决方案**：
- 标签处开始新基本块
- 跳转指令结束当前基本块
- 记录跳转目标建立边
