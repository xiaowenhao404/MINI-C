# Mini-C Web IDE 测试指南

## 测试前准备

### 1. 确保编译器已编译

```bash
# 在项目根目录
cd Mini-C
make

# 验证编译器存在
ls -l compiler
```

### 2. 安装 Python 依赖

```bash
cd web
pip install -r requirements.txt
```

## 测试步骤

### 测试1：Flask 服务器启动

```bash
cd web
python app.py
```

**预期输出**：
```
==================================================
  Mini-C 编译器可视化界面正在启动...
==================================================

✓ Flask 服务器
✓ 端口: 5000
✓ 访问地址: http://127.0.0.1:5000
...
```

**验证**：
- 浏览器访问 `http://127.0.0.1:5000`
- 应该看到 Mini-C IDE 界面

### 测试2：界面加载

**检查项**：
- [ ] 顶部标题栏显示正常（红黄绿三点、标题、编译按钮）
- [ ] 左侧代码编辑器加载正常
- [ ] 代码有语法高亮（关键字显示蓝色）
- [ ] 右侧有4个标签页（Token流、AST、IR、ASM）
- [ ] 底部控制台显示欢迎信息

### 测试3：编译功能

**测试代码1**（基础功能）：
```c
void main() {
    int a = 10;
    int b = 20;
    int c = a + b;
    output_int(c);
}
```

**操作**：
1. 清空编辑器
2. 粘贴上述代码
3. 点击 "编译与运行" 按钮

**预期结果**：
- 控制台显示编译过程
- Token流标签页显示词法分析结果
- AST标签页显示语法树
- IR标签页显示中间代码（如 `1 c = a + b`）
- ASM标签页显示汇编代码

---

**测试代码2**（浮点运算）：
```c
void main() {
    float x = 3.14;
    float y = 2.0;
    float sum = x + y;
    output_float(sum);
}
```

**预期结果**：
- IR 包含浮点指令（`f+`）
- ASM 包含 SSE 指令（`movss`, `addss`）

---

**测试代码3**（常量折叠优化）：
```c
void main() {
    int a = 3 + 4 * 5;
    output_int(a);
}
```

**预期结果**：
- IR 中 `a = 23`（常量已折叠）
- 没有中间计算指令

---

**测试代码4**（死代码消除）：
```c
void main() {
    int a = 10;
    
    if (0) {
        output_int(999);
    }
    
    output_int(a);
}
```

**预期结果**：
- IR 中没有 `output_int(999)` 相关指令
- if(0) 分支被删除

### 测试4：标签页切换

**操作**：
1. 编译任意代码
2. 依次点击4个标签页

**预期结果**：
- 点击后标签按钮变为激活状态（蓝色下划线）
- 内容区域显示对应文件内容
- 切换流畅，无延迟

### 测试5：错误处理

**测试代码**（语法错误）：
```c
void main() {
    int a = 10  // 缺少分号
    output_int(a);
}
```

**预期结果**：
- 控制台显示错误信息
- 标签页显示"未生成"提示

---

**测试代码**（语义错误）：
```c
void main() {
    int a = b;  // b 未定义
}
```

**预期结果**：
- 控制台显示语义错误
- 相关中间文件可能不完整

### 测试6：快捷键

**操作**：
- 按 `Ctrl+Enter` (Windows) 或 `Cmd+Enter` (Mac)

**预期结果**：
- 触发编译，效果同点击按钮

### 测试7：控制台输出

**验证内容**：
- 显示编译步骤
- 显示文件生成状态
- 显示错误信息（如果有）
- 信息清晰易读

## 故障排查

### 问题：页面空白

**解决**：
1. 打开浏览器控制台（F12）
2. 查看是否有 JavaScript 错误
3. 检查 CodeMirror CDN 是否加载成功

### 问题：编译无响应

**解决**：
1. 检查 Flask 服务器日志
2. 确认编译器路径正确
3. 检查网络请求（F12 → Network）

### 问题：中间文件不显示

**解决**：
1. 检查编译器是否正确执行
2. 确认文件生成在正确位置
3. 查看控制台错误信息
