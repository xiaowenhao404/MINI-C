新增指令:
- FUNC_BEGIN: 标记函数开始
- FUNC_END: 标记函数结束
- PARAM: 函数参数传递（增强）
- CALL: 函数调用（增强）
- RETURN: 返回语句（增强）

IR 格式示例:
```
FUNC_BEGIN add
t0 = a + b
return t0
FUNC_END add

FUNC_BEGIN main
arg 10
arg 20
t1 = call add 2
```
